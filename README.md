# Embodied Agent Survey

A curated paper list and research repository for
**Embodied Agent Technologies**, focusing on how intelligent
agents perceive, reason, plan, execute, learn, and reliably
interact with the physical world.

## 🎯 Scope

This repository focuses on embodied agents that integrate
high-level intelligence with physical interaction.

We organize the literature around five core capabilities:

1. Foundation Models & Embodied Perception
2. Planning, Reasoning & Task Decomposition
3. Skills, Tool Use & Action Execution
4. Memory, Continual Learning & Self-Evolution
5. Agentic Systems, Reliability & Generalization


## 🧭 Taxonomy

Embodied Agent
│
├── Perceive & Understand
├── Reason & Plan
├── Execute & Act
├── Remember & Learn
└── Monitor, Recover & Generalize

## 📝 Survey Writing

The repository supports an ongoing survey on
Embodied Agent Technologies.

Rather than simply listing individual papers, we aim to
identify:

- major technical paradigms;
- historical evolution;
- relationships between research directions;
- representative systems;
- limitations and open challenges.
